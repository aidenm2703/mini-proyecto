# Prompts utilizados durante el desarrollo

Este documento recoge los prompts clave empleados para construir el sistema administrativo y sus módulos principales. Se ha mantenido en formato de lista para facilitar la entrega final del proyecto.

## 1) Diseño general del sistema

- Prompt 1: "Crea una interfaz web de tipo sistema administrativo con login, sidebar y dashboard para una empresa. Debe tener un diseño moderno, responsivo y atractivo visualmente."
- Prompt 2: "Diseña una pantalla de inicio con dos tipos de acceso: administrador y usuario. El administrador debe ver gestión completa del sistema y el usuario debe acceder a su portal personal."
- Prompt 3: "Haz que la pantalla de login tenga botones para elegir el tipo de acceso y una validación simple con usuario y contraseña."

## 2) Módulos de administración

- Prompt 4: "Implementa un CRUD para clientes con campos de nombre, cédula, email, teléfono, dirección y estado. Debe poder crear, listar, buscar y eliminar registros."
- Prompt 5: "Crea un CRUD para productos con nombre, código, categoría, precio, stock, estado y descripción. Muestra el inventario y el estado de cada producto."
- Prompt 6: "Desarrolla la gestión de proveedores con nombre, cédula jurídica, teléfono, email, dirección, categoría, estado y contacto."

## 3) Encuestas, personal y tareas

- Prompt 7: "Agrega una sección de encuestas para administradores con métricas, resultados y tablas visuales."
- Prompt 8: "Implementa una vista de empleados y tareas para asignar tareas a usuarios, crear reuniones y mostrar notificaciones relevantes."
- Prompt 9: "Crea una funcionalidad de reuniones con invitación múltiple a empleados y almacenamiento local en el navegador."

## 4) Portal del colaborador

- Prompt 10: "Diseña un portal del colaborador con asistencia, calendario laboral, evaluación de desempeño, plan de carrera, formación, permisos y noticias."
- Prompt 11: "Haz que cada módulo del portal pueda abrirse como una página individual con una barra lateral y menú de navegación."
- Prompt 12: "Añade notificaciones para tareas, reuniones, permisos y cambios de estado usando almacenamiento local."

## 5) Experiencia de usuario y accesibilidad

- Prompt 13: "Incluye sonidos de confirmación, alarmas y alertas de seguridad con Web Audio API para mejorar la experiencia del sistema."
- Prompt 14: "Añade soporte multilenguaje para español e inglés en el portal y en los textos principales."
- Prompt 15: "Implementa una simulación de verificación biométrica para la pantalla de login y un manejo visual de errores."

## 6) Ajustes finales y correcciones

- Prompt 16: "Corrige los errores de navegación para que el botón Volver regrese al inicio correcto según el rol del usuario."
- Prompt 17: "Mejora la compatibilidad del proyecto con navegación por secciones, tabla dinámica y persistencia de datos en localStorage."
- Prompt 18: "Haz una revisión final del portal para asegurar que el dashboard, módulos de gestión y módulos de empleado funcionen de forma consistente."

## 7) Observación del equipo

Los prompts anteriores fueron adaptados y combinados durante el desarrollo del proyecto para corregir detalles visuales, de lógica y de usabilidad. El sistema final se ejecuta principalmente con HTML, CSS y JavaScript puro, sin depender de un framework externo.
