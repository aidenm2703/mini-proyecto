# Carpeta de capturas

Esta carpeta está reservada para guardar las capturas de pantalla del sistema funcionando.

Se recomienda incluir:
- Login principal
- Dashboard administrativo
- CRUD de clientes o productos
- Portal del colaborador
- Módulo de encuesta o calendario

Guarda las imágenes con nombres descriptivos, por ejemplo:
- login.png
- dashboard-admin.png
- clientes.png
- portal-usuario.png
