# Checklist de entrega final

## 1. Código fuente completo
- [ ] Proyecto completo subido en el repositorio.
- [ ] Archivos principales incluidos: HTML, CSS, JS y recursos gráficos.
- [ ] No faltan módulos del sistema ni dependencias básicas del proyecto.

## 2. Repositorio Git
- [ ] Repositorio público o accesible con permisos adecuados.
- [ ] URL del repositorio registrada: https://github.com/aidenm2703/mini-proyecto.git
- [ ] Historial de commits disponible.
- [ ] Ramas visibles: Ana, Aiden, main.
- [ ] Pull requests y ramas documentadas si se usan en la entrega final.

## 3. Carpeta organizada del proyecto
- [ ] Estructura clara y comprensible.
- [ ] Archivos de lógica, estilo y páginas separadas.
- [ ] Recursos gráficos y documentos añadidos en carpetas adecuadas.

## 4. README explicativo
- [ ] Archivo README.txt/README.md con descripción del proyecto.
- [ ] Explicación de funcionamiento y módulos del sistema.
- [ ] Indicaciones de ejecución en navegador.
- [ ] Credenciales de prueba y estructura del proyecto.

## 5. Documento de prompts
- [ ] Archivo con los prompts usados durante el desarrollo.
- [ ] Listado de solicitudes clave para diseño, funcionalidad y correcciones.

## 6. Capturas de pantalla
- [ ] Captura del login.
- [ ] Captura del dashboard administrativo.
- [ ] Captura de un módulo de gestión (clientes, productos o proveedores).
- [ ] Captura del portal del colaborador o módulo de usuario.
- [ ] Guardar las imágenes en la carpeta capturas/.

## 7. Verificación antes de entregar
- [ ] Comprobar que el proyecto se abre correctamente en navegador.
- [ ] Confirmar que la autenticación funciona con las credenciales de prueba.
- [ ] Confirmar que se guardan datos en localStorage.
- [ ] Revisar que el sistema responde y no presenta errores visibles.

## 8. Entrega recomendada
- [ ] Enviar el enlace del repositorio GitHub.
- [ ] Añadir el archivo README.md.
- [ ] Añadir la carpeta capturas/ con las imágenes del sistema.
- [ ] Incluir el documento PROMPTS_DESARROLLO.md.
- [ ] Presentar una breve demostración del funcionamiento en clase o en la entrega final.
